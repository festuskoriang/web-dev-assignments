# SpendWise – Personal Budget & Expense Tracker

## 1. Project Description

SpendWise is a personal finance and expense tracking web application designed to help users manage their money, create monthly budgets, and monitor their spending.

The application allows users to:
- Set and update their monthly budget.
- Add and delete expense records.
- Categorize expenses.
- Calculate total expenses automatically.
- Monitor their remaining budget.
- Search through recorded transactions.
- View spending patterns using charts.
- Save information using browser LocalStorage.

SpendWise provides a clean, responsive dashboard that makes managing personal finances easier.

## 2. Technologies Used

The project was developed using the following technologies:

- **HTML5:** Used to create the structure and content of the application.
- **CSS3:** Used for styling, responsive design, CSS Grid, Flexbox, and layouts.
- **JavaScript:** Used to implement application functionality, calculations, conditional statements, arrays, loops, event listeners, and DOM manipulation.
- **Chart.js:** Used to create expense category and spending trend charts.
- **Google Fonts:** Used to improve typography and readability.
- **LocalStorage:** Used to save expense records, budget information, and theme preferences in the browser.

## 5. Deployment Process Summary

The application was deployed using GitHub and Netlify.

The deployment process involved:

1. Developing the application using HTML, CSS, and JavaScript.
2. Organizing the project into separate source files.
3. Testing the application locally using a web browser.
4. Creating a GitHub repository and uploading the project files.
5. Connecting the GitHub repository to Netlify.
6. Configuring Netlify to publish the static website.
7. Deploying the application and obtaining a public website URL.
8. Accessing the live website to check the deployed application.

Netlify makes it possible to host the application online without requiring a traditional web server.

## 6. Challenges Encountered During Deployment

Some of the technical challenges and considerations during development and deployment included:

- **File organization:** Ensuring that HTML, CSS, and JavaScript files were correctly linked.
- **Responsive design:** Making sure the dashboard displays properly on different screen sizes.
- **JavaScript functionality:** Ensuring that forms, calculations, and transaction updates work correctly.
- **External libraries:** Ensuring that Chart.js loads correctly through its CDN.
- **Deployment configuration:** Selecting the correct publishing directory in Netlify.

These challenges highlighted the importance of organizing project files properly and testing an application before and after deployment.
